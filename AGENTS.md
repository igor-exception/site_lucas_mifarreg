# AGENTS.md — Site Profissional Lucas Alvarenga Mifarreg

## Objetivo do projeto

Este repositório contém o site profissional de Lucas Alvarenga Mifarreg.

O site é baseado no template Spectral do HTML5 UP e será publicado no GitHub Pages.

O objetivo é transformar o template original em uma apresentação profissional simples, elegante e internacional de Lucas.

## Fonte de verdade

Antes de criar ou alterar conteúdo profissional, leia:

CONTEXTO-LUCAS.md

Considere esse arquivo a principal fonte factual sobre Lucas.

Não invente:
- empregos;
- cargos;
- empresas;
- datas;
- formação;
- certificações;
- cidades;
- responsabilidades;
- resultados quantitativos;
- experiência profissional no exterior.

Se alguma informação necessária não estiver disponível, deixe um TODO ou pergunte ao usuário.

## Público

O site será voltado principalmente para recrutadores e empresas.

A mensagem deve ser profissional, objetiva e fácil de compreender rapidamente.

## Idiomas do site

O site deverá possuir:

- Português
- Inglês
- Espanhol

A versão inicial pode usar português como idioma padrão.

A navegação entre idiomas deverá ser simples e clara.

Prefira URLs separadas:

/
 /en/
 /es/

As três versões devem manter o mesmo design e estrutura.

## Design

Manter como base visual o Spectral do HTML5 UP.

Não reconstruir o site desnecessariamente.

Preservar:
- responsividade;
- estrutura principal;
- animações úteis;
- comportamento mobile;
- compatibilidade com GitHub Pages.

O resultado deve parecer um site profissional, e não um portfólio de desenvolvedor.

Evitar:
- excesso de efeitos;
- barras de porcentagem de skills;
- seções sem conteúdo real;
- textos exageradamente longos;
- linguagem de marketing artificial.
